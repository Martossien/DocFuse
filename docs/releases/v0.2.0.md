# DocFuse 0.2.0 beta

Première version sous son vrai nom : **DocFuse** (le nom de code « CorpusOne »
disparaît des exécutables, dossiers et fichiers de configuration). Elle
apporte la fonctionnalité qui manquait pour alimenter une LLM à partir de
gros volumes : le **découpage automatique en plusieurs corpus** sous le
plafond de contexte, sans jamais couper un fichier.

## Points principaux

### Découpage en plusieurs corpus (`--split-context`)

Quand le total — ou un fichier — dépasse le plafond, DocFuse ne bloque plus
si l'option est active : il écrit `corpus_001.md`, `corpus_002.md`… (ou
`.pdf`), chacun sous le plafond, en remplissant dans l'ordre du tri. **Un
fichier n'est jamais coupé** ; un fichier qui dépasse à lui seul le plafond
est isolé dans sa propre partie et signalé dans le préambule et le rapport.
Le rapport unique liste les parties et la partie de chaque fichier. Option
disponible en ligne de commande, dans la config JSON (`"split_context"`) et
dans l'interface (case « Découper en plusieurs corpus »). En bibliothèque :
`split_by_budget()` et `generate_corpus_parts()`.

### DocFuse, pas CorpusOne

Exécutables `DocFuse.exe` / `DocFuse-OCR.exe`, dossier de sortie
`DocFuse_output/`, config `DocFuse.json` ou `%APPDATA%\DocFuse\`, journal
`%TEMP%\DocFuse\docfuse.log`. Une configuration `CorpusOne.json` héritée
d'une version 0.1.x est encore lue. Le nom est paramétrable pour une
distribution interne : `DOCFUSE_APP_NAME=MonOutil` (au lancement, et au
build PyInstaller pour nommer l'exécutable).

### Bibliothèque Python

`pip install docfuse` installe le cœur (CLI + bibliothèque) sans Tk ;
`pip install "docfuse[gui]"` ajoute l'interface. `py.typed` expose les
annotations. L'exemple « Utiliser comme bibliothèque » du README, faux
depuis 0.1.6, est corrigé.

## Choix techniques notables

- Aucune nouvelle dépendance. Décisions D-101 à D-103 dans
  `docs/journal-decisions.md`.
- Le mode découpage est **désactivé par défaut** : le comportement du cahier
  des charges (blocage, code retour 2) est inchangé.

## Installation Windows

1. Télécharger l'archive ci-dessus (et son `.sha256`) — `DocFuse` pour
   l'usage standard, `DocFuse-OCR` pour l'OCR des scans sans installer
   Tesseract.
2. Extraire **le seul** `.exe` de l'archive vers un dossier de votre choix.
3. Lancer l'exe. Aucun droit administrateur, aucune connexion réseau.

Le binaire n'est pas signé : Windows SmartScreen peut afficher un
avertissement au premier lancement. Vérifiez l'empreinte SHA-256.

## Limites de cette beta

- Les specs PyInstaller renommés n'ont pas été buildés localement (pas de
  machine Windows ici) : le premier build CI de cette version vérifiera la
  prise en compte de `DOCFUSE_APP_NAME`.
- Le découpage ne coupe jamais un fichier : un document plus gros que le
  plafond reste seul dans sa partie, hors plafond — à vous d'augmenter le
  plafond ou de le retirer.
