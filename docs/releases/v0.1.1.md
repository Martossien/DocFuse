# CorpusOne 0.1.1 beta

Cette préversion Windows portable stabilise la sélection de documents, l'affichage de
la progression et le calcul approximatif du contexte destiné à un LLM.

## Points principaux

- Ajout cumulatif de plusieurs fichiers et dossiers dans la GUI.
- Affichage immédiat des fichiers inventoriés, puis mise à jour de leur statut et de leur
  estimation de tokens.
- Mise en page plus compacte et responsive ; le plafond de contexte (128 K par défaut)
  reste visible sans agrandir la fenêtre.
- Retrait individuel d'un fichier avec recalcul instantané, sans nouvelle extraction.
- Calcul fiabilisé sur les octets UTF-8 exacts, en-têtes `SOURCE` compris ; la marge est
  appliquée une seule fois au total.
- Build PyInstaller corrigé pour embarquer tous les extracteurs chargés dynamiquement.

## Correctifs de build (post-publication initiale)

- **Binaire `--onefile`** : le binaire Windows est désormais un unique `CorpusOne.exe`
  autoportant (~40.6 Mo). La runtime Python (python313.dll, VCRUNTIME140) et toutes les
  dépendances natives sont embarquées dans l'exe — fini les « DLL Python 3.13 manquante »
  quand on déplace le fichier. CdC §5.1, option privilégiée.
- **DLL natives embarquées** : `tcl86t.dll`, `tk86t.dll`, `zlib1.dll`, `libffi-8.dll`,
  `libssl-3.dll`, `libcrypto-3.dll`, `sqlite3.dll` sont collectées depuis `<python>/DLLs/`
  et incluses dans le bundle. Sans elles, `_tkinter` (GUI CustomTkinter), `_ctypes`,
  `_ssl` et `_sqlite3` levaient `ImportError: DLL load failed` au démarrage.
- **CLI** : `--output <dossier>` (sans extension) est désormais un cas légitime : la CLI
  ajoute automatiquement `.md` ou `.pdf` selon `--format` et crée le dossier au besoin.

## Installation Windows

1. Télécharger l'archive ci-dessus :
   [CorpusOne-0.1.1-beta-windows-x64.zip](https://github.com/Martossien/DocFuse/releases/download/v0.1.1/CorpusOne-0.1.1-beta-windows-x64.zip)
   (et éventuellement son
   [.sha256](https://github.com/Martossien/DocFuse/releases/download/v0.1.1/CorpusOne-0.1.1-beta-windows-x64.zip.sha256)
   pour vérification).
2. Extraire **le seul** `CorpusOne.exe` de l'archive vers un dossier de votre choix
   (clé USB, dossier utilisateur, partage réseau). Aucun autre fichier n'est requis :
   le runtime Python est embarqué dans l'exe.
3. Lancer `CorpusOne.exe` (double-clic). Aucun droit administrateur et aucune connexion
   réseau ne sont nécessaires.

Le binaire n'est pas signé : Windows SmartScreen peut afficher un avertissement lors du
premier lancement. Vérifiez l'empreinte SHA-256 avant l'exécution.

## Validation

- 236 tests collectés : **199 réussis**, 38 ignorés parce que le jeu local
  `tests/samples_real/` n'est pas versionné (+1 test de non-régression pour le fix CLI).
- `ruff check`, `ruff format --check` et `mypy --strict` validés sur 38 fichiers source.
- Recette fonctionnelle : **7/7 PASS**.
- Binaire onefile testé avec succès :
  - `CorpusOne.exe --version` → `docfuse 0.1.1`, exit 0.
  - `CorpusOne.exe --input ... --output ... --format md --yes` → corpus + rapport MD +
    rapport JSON générés, exit 0.
  - Lancement GUI CustomTkinter sans erreur DLL.

## Limites de cette beta

- Pas d'OCR : les documents constitués uniquement d'images sont signalés, pas reconnus.
- L'estimation du contexte reste volontairement générique (`octets UTF-8 / 4`, marge de
  15 % par défaut) et ne remplace pas le tokenizer exact d'un modèle particulier.
- Les 38 tests fondés sur des documents réels restent à rendre reproductibles dans un
  clone frais.
